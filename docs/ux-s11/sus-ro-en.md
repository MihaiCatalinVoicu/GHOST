# S11 — SUS (System Usability Scale), EN + RO

Se aplică o dată, la finalul sesiunii, pe build-ul testat. Scală 1–5 (1 = dezacord total, 5 = acord
total). Scorul standard: (suma − 5) × 2,5 pe 100; 68 e media de referință a literaturii (informativ,
nu prag de trecere — pragul de poartă e la erori critice și înțelegere).

**EN.** 1. I think that I would like to use this system frequently. 2. I found the system unnecessarily
complex. 3. I thought the system was easy to use. 4. I think that I would need the support of a
technical person to be able to use this system. 5. I found the various functions in this system were
well integrated. 6. I thought there was too much inconsistency in this system. 7. I would imagine that
most people would learn to use this system very quickly. 8. I found the system very cumbersome to use.
9. I felt very confident using the system. 10. I needed to learn a lot of things before I could get
going with this system.

**RO.** 1. Aș folosi acest sistem frecvent. 2. Am găsit sistemul inutil de complex. 3. Mi s-a părut că
sistemul este ușor de folosit. 4. Aș avea nevoie de ajutorul unei persoane tehnice ca să folosesc
acest sistem. 5. Am găsit funcțiile acestui sistem bine integrate. 6. Mi s-a părut că sistemul este
prea inconsistent. 7. Cred că majoritatea oamenilor ar învăța repede să folosească acest sistem.
8. Am găsit sistemul foarte greoi de folosit. 9. M-am simțit foarte sigur/ă folosind sistemul.
10. A trebuit să învăț multe lucruri înainte să pot începe cu acest sistem.

Items 2, 4, 6, 8, 10 se inversează la scor. RO se folosește cu participanții români; EN cu cei
internaționali (runda anonimă poate avea ambele).
