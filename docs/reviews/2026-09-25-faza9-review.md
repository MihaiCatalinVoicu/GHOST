## Refuted

- **A-7** (low): "the release APK embeds `version-control-info.textproto`, whose bytes depend on how the source was checked out". AGP 9.4 reads VCS information from the Gradle root (`ghost/android`), which is never a git root in any checkout of this repository, so the entry is the same 46-byte error form in every build and carries no commit id. No change; `vcsInfo { include = false }` would be defensive hardening only.

## The regression test

`PhaseReviewRegressionTest` (`45e1f9a`) runs the engine findings on `DmWorld` with the real native library. With every engine fix of this review turned off at once (a script that reverts each fix in place and keeps the new APIs so the test compiles), **11 of 11 fail**, each at the defect it names: the CHECK and trigger aborts (ENG-1, ENG-3, ENG-4), the escaping `StorageFullException` (ENG-2, twice), `2 592 000` for `604 800` (ENG-5), `870` s for the EST timer (MD-3), attempt 2 opened by the alarm at +380 min (MD-2), two orphan rows kept (ENG-7), the gap still held 13 minutes after the step (ENG-8), the own message swept (ENG-6).
